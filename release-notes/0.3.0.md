# ym-sync 0.3.0

- Вход в аккаунт прямо из приложения
- «Играть следующим»
- Перемешивание и повтор для всей комнаты
- Свои плейлисты в коллекции
- Текст песни, синхронный с музыкой
- Кто в комнате и ники участников
- Страница настроек на ПК

**Важно:** 0.3.0 не совместима с 0.2.x — обновите все устройства комнаты

**Установка:** Windows — `ym-sync_0.3.0_x64-setup.exe` (или автообновление), Android — `ymsync-0.3.0-android.apk` (ставится поверх 0.2.x)
