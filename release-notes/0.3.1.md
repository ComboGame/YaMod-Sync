# ym-sync 0.3.1

- Трек начинается у всех одновременно и с начала — когда загрузится на каждом устройстве
- Треки, недоступные аккаунту, берутся у участников комнаты
- Кнопка «в плейлист» у играющего трека и плейлисты на устройстве
- Свои файлы в плейлистах и очереди, со значком
- Страница исполнителя по нажатию на его имя
- Кнопка «Скачать» в «Мне нравится»

**Установка:** Windows — `ym-sync_0.3.1_x64-setup.exe` (или автообновление), Android — `ymsync-0.3.1-android.apk` (ставится поверх 0.3.0)
