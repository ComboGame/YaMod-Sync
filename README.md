# Яндекс Музыка Sync

Десктопная Яндекс Музыка со встроенным совместным прослушиванием. Вы и друзья
заходите в одну комнату, и у всех играет одно и то же с одной позиции. Пауза,
перемотка, очередь и «Моя волна» общие, управлять может любой: из панели Sync
или обычными кнопками приложения.

Только для пользователей с **подпиской Плюс**: каждый слушает со своего
аккаунта, приложение не открывает платное и не скачивает музыку.

**[Скачать последнюю версию](https://github.com/ComboGame/YaMod-Sync/releases/latest)** · Windows 10/11, x64 ·
приложение для Android — в [Releases](https://github.com/ComboGame/YaMod-Sync/releases) с тегом `android-v…`

## Возможности

| | |
|---|---|
| Комната | Вход по адресу сервера (`ws://IP:8787` или `wss://домен`) и паролю. Можно держать комнату прямо на своём компьютере, без сервера |
| Синхрон | Плеер приложения следует за комнатой; после выравнивания расхождение порядка единиц миллисекунд |
| Кнопки приложения | Пауза, перемотка, «вперёд» и «назад», включённый альбом или плейлист становятся командами для всей комнаты |
| «Моя волна» для всех | Треки подбираются для того, кто включил волну, а Яндекс получает обратную связь: что начали, дослушали, пропустили |
| Панель Sync | Сейчас играет, очередь комнаты, участники, расхождение с комнатой, настройки — в стиле самого приложения |
| Остальное | Discord Rich Presence, высокое качество по умолчанию, свой шрифт, перенос треков лайками из плейлиста |

## Как начать

1. **Сервер комнаты.** Нужен один на всю компанию: VDS с Docker, развёртывание
   занимает несколько минут — см. [«Сервер»](#сервер). Если все в одной сети
   или у кого-то есть белый IP, можно обойтись без него: включите в панели Sync
   «Держать комнату на этом компьютере», остальные подключаются к вам.
2. **Приложение.** Скачайте `YandexMusicSync-Setup-<версия>.exe` из
   [Releases](https://github.com/ComboGame/YaMod-Sync/releases) и установите.
   Оно ставится рядом с обычной Яндекс Музыкой и держит отдельный профиль,
   поэтому в первый раз нужно войти в аккаунт Яндекса. Установщик не подписан:
   если Windows SmartScreen предупредит, нажмите «Подробнее» → «Выполнить в
   любом случае».
3. **Комната.** Кнопка **Sync** рядом с профилем → вкладка «Комната» → адрес
   сервера, название комнаты и пароль, одинаковые у всех → «Войти в комнату».

Автообновление приложения отключено, чтобы поверх Sync не встала обычная
Яндекс Музыка. Новые версии выходят в Releases.

## Телефон

Приложение для Android (8.0+) — своё, не на основе приложения Яндекса: «Моя волна»
с режимами, «Мне нравится», комнаты как на ПК и плеер с уведомлением на экране
блокировки. В комнате телефон слушает вместе с компьютерами. Установка, обновления
и выпуск версий — [docs/android.md](docs/android.md).

## Сервер

Комнату держит `ymsync-relay` — небольшой WebSocket-сервер. Звук через него не
идёт, только команды и метки времени, так что хватит самого дешёвого VDS.

```bash
git clone https://github.com/ComboGame/YaMod-Sync.git /opt/yamod-sync
cd /opt/yamod-sync
cp .env.example .env
sed -i "s/^YMSYNC_ROOM_TOKEN=.*/YMSYNC_ROOM_TOKEN=$(openssl rand -hex 16)/" .env
docker compose up -d --build
```

Пароль комнаты — значение `YMSYNC_ROOM_TOKEN` в `.env`, адрес сервера —
`ws://IP_СЕРВЕРА:8787` (откройте TCP 8787). С доменом и TLS через Caddy:
`docker compose --profile tls up -d --build`, адрес — `wss://ваш.домен`.

Пошагово, включая установку Docker, TLS, работу за nginx и разбор ошибок, —
[docs/server.md](docs/server.md).

## Как это устроено

```
 окно приложения                         main-процесс              ymsync-bridge.exe
 ┌────────────────────────────┐   IPC    ┌───────────────┐  stdio  ┌──────────────────────┐
 │ плеер Яндекса (Sonata)     │◄────────►│ yandex-sync.ts│◄───────►│ ядро: связь с релеем, │──► ymsync-relay
 │ features/yandex-sync       │          └───────────────┘  JSON   │ часы, очередь, волна  │    (сервер)
 │ панель Sync (React)        │                                    └──────────────────────┘
 └────────────────────────────┘
```

Установщик — это официальная Яндекс Музыка для Windows, пропатченная при
сборке: в неё добавляются панель Sync, связка с плеером и мост к ядру синхрона.
Плеер остаётся плеером Яндекса: ядро говорит, что поставить, когда играть и
куда перемотать, а окно отвечает, что плеер делает на самом деле.

| Каталог | Что внутри |
|---|---|
| `mod/` | Патчер (`src/patcher`) и сам мод: панель Sync, связка с плеером (`src/mod/features/yandex-sync`), main-часть с запуском моста (`src/mod/main`) |
| `crates/bridge` | `ymsync-bridge.exe`: ядро синхрона для плеера в другом процессе, общается с приложением строками JSON по stdin/stdout |
| `crates/core` | Библиотека ядра: клиент API Яндекс Музыки, связь с релеем, движок синхрона, «Моя волна» |
| `crates/relay` | `ymsync-relay`: сервер комнаты — участники, общие часы, очередь и позиция |
| `crates/proto` | Формат сообщений, оценка смещения часов, математика коррекции |
| `android/` | Приложение для Android: Kotlin, Jetpack Compose, Media3 (уведомление и кнопки) |
| `crates/android` | Ядро для телефона через JNI: то же ядро, свой плеер (rodio) и своя комната, когда слушаете одни |
| `deploy/`, `Dockerfile`, `docker-compose.yml` | Развёртывание сервера |

## Сборка

### Установщик (Windows)

Нужны [Bun](https://bun.sh) 1.1.27, Rust 1.90+ и Visual Studio Build Tools с
компонентом C++.

```powershell
cd mod
bun install
bun run start      # скачать актуальную Яндекс Музыку, пропатчить, собрать мост и установщик
```

Установщик появится в `mod/.versions/<версия>/mod/dist/YandexMusicSync-Setup-<версия>.exe`.

Для разработки:

```powershell
bun run dev        # то же без установщика: .versions/<версия>/mod для запуска через electron
bun run ui:dev     # пересобрать части мода в уже подготовленной папке
```

Патчер проверяет каждую правку приложения: если в новой версии Яндекс Музыки
нужное место не нашлось, сборка останавливается с понятной ошибкой, а не выдаёт
сборку, которая только кажется рабочей. Если GitHub-релизы недоступны, задайте
зеркала `ELECTRON_MIRROR` и `ELECTRON_BUILDER_BINARIES_MIRROR`.

### Сервер и тесты

```bash
cargo test --workspace
cargo build --release -p ymsync-relay
```

### Android

Нужны Android SDK и NDK, JDK 17+ и Rust с таргетами Android и `cargo-ndk`.

```powershell
cargo ndk -t arm64-v8a -t armeabi-v7a -t x86_64 --platform 26 -o crates/android/jniLibs build --release -p ymsync-android
cd android
.\gradlew.bat testDebugUnitTest assembleDebug
```

Подробнее — [docs/android.md](docs/android.md).

### Релизы

Релизы собирает GitHub Actions ([`.github/workflows/release.yml`](.github/workflows/release.yml))
на Windows. Чтобы выпустить новую версию, поднимите номер в `mod/VERSION` и
запушьте: workflow соберёт установщик и опубликует релиз `mod-v<версия>` с
контрольной суммой. Приложение для Android выпускает
[`.github/workflows/android-release.yml`](.github/workflows/android-release.yml)
по версии из `android/version.properties` — релиз `android-v<версия>`.
