# Яндекс Музыка Sync

Десктопная Яндекс Музыка со встроенным совместным прослушиванием
[YandexSync (ym-sync)](https://github.com/mshivarev/ym-sync). Вы и друзья
заходите в одну комнату, и у всех играет одно и то же с одной позиции. Пауза,
перемотка, очередь и «Моя волна» общие, управлять может любой: из панели мода
или обычными кнопками приложения.

Мод работает с **вашей подпиской Плюс**: треки играют с вашего аккаунта, мод
не открывает платное и не скачивает музыку. Он вырос из Yandex Music Mod 2.23.2.
Обход подписки, подмена ответов API и загрузчик треков из него убраны.

## Что внутри

| | |
|---|---|
| Комната | вход по адресу сервера (`ws://IP:8787` или `wss://домен`) и паролю, или комната на этом компьютере |
| Синхрон | плеер приложения следует за комнатой; после выравнивания расхождение порядка единиц миллисекунд |
| Кнопки приложения | пауза, перемотка, «вперёд»/«назад», включённый альбом или плейлист становятся командами комнаты |
| «Моя волна» | для всей комнаты: треки подбираются для того, кто её включил, Яндексу уходит обратная связь (начал, дослушал, пропустил) |
| Остальное | Discord Rich Presence, высокое качество по умолчанию, свой шрифт, перенос лайками из плейлиста, режим разработчика |

Мод ставится рядом с обычной Яндекс Музыкой и держит отдельный профиль: в
первый раз нужно войти в аккаунт. Автообновление отключено, чтобы поверх мода
не встала обычная версия.

## Как это устроено

```
 окно приложения                           main-процесс              ymsync-bridge.exe
 ┌──────────────────────────────┐   IPC    ┌───────────────┐  stdio  ┌───────────────────────┐
 │ плеер Яндекса (Sonata)       │◄────────►│ yandex-sync.ts│◄───────►│ ядро ym-sync: релей,   │──► релей комнаты
 │ features/yandex-sync         │          └───────────────┘  JSON   │ часы, очередь, волна   │
 │ панель мода (React)          │                                    └───────────────────────┘
 └──────────────────────────────┘
```

- `src/mod/features/yandex-sync/sonata.ts` находит фасад плеера приложения и
  ставит треки по id (`setContext` / `setEntityByIndex` / `setProgress`).
- `controller.ts` выполняет указания ядра, 5 раз в секунду сообщает позицию и
  перехватывает методы плеера, которые вызывают кнопки приложения.
- `src/mod/main/yandex-sync.ts` запускает `ymsync-bridge.exe` из `crates/bridge`
  репозитория ym-sync и пересылает сообщения. Пока вы в комнате, окно не
  замедляется в фоне.
- Ядро — тот же движок, что в приложениях ym-sync; у него другой только плеер
  (`RemotePlayback`).

## Сборка

Нужны [Bun](https://bun.sh), Rust 1.90+ с MSVC (Visual Studio Build Tools с
компонентом C++) и этот каталог внутри репозитория ym-sync (мост собирается из
`../crates/bridge`; другой путь задаёт `YMSYNC_REPO`, готовый exe — `YMSYNC_BRIDGE`).

```powershell
bun install
# Если GitHub-релизы недоступны:
$env:ELECTRON_MIRROR = "https://npmmirror.com/mirrors/electron/"
$env:ELECTRON_BUILDER_BINARIES_MIRROR = "https://npmmirror.com/mirrors/electron-builder-binaries/"

bun run start      # скачать актуальную сборку Яндекс Музыки, пропатчить, собрать установщик
bun run dev        # то же без установщика: .versions/<версия>/mod для `electron .`
bun run ui:dev     # пересобрать части мода в уже подготовленной папке
```

Установщик появится в `.versions/<версия>/mod/dist/YandexMusicSync-Setup-<версия>.exe`.

Патчер проверяет каждую правку приложения: если в новой версии Яндекс Музыки
нужное место не нашлось, сборка останавливается с понятной ошибкой и не выдаёт
мод, который только кажется рабочим.

## Сервер комнаты

Комнату держит `ymsync-relay` — например, на VDS через Docker. Как поднять, см.
`docs/vds-docker.md` в репозитории ym-sync.
